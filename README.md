# 色のやつ v1

専門的な色の数値を入力せず、基本色・明るさ・寄せたい色という日常的な操作で色を決める、モバイルファーストの静的Webツールです。

## 起動

ES Modulesを使うため、任意の静的HTTPサーバーでリポジトリ直下を配信してください。

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

## テスト

Node.js 18以降で実行できます。外部パッケージは不要です。

```sh
npm test
```

色は内部でOKLCHとして保持します。明るさは1操作で `L ± 0.05`、色味は現在のLを保ちながら目標のCとhへ15%近づきます。sRGB外の色はLとhを固定し、Cだけを固定回数の二分探索で減らしてから6桁HEXへ変換します。
